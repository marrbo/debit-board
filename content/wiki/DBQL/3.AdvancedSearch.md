# AdvancedSearch 
### DBQL - DebitBoard Query Language v2.0

O componente `AdvancedSearch` é o motor de buscas avançadas e filtragem de dados, projetado para suportar desde buscas visuais simples através de tags até queries complexas utilizando a DebitBoard Query Language (DBQL).

## 🛠 Funcionalidades Principais

* **Modos de Busca Híbridos:** 

  * **Modo Tags:** Interface simplificada onde os filtros são renderizados como chips visuais, ideal para buscas rápidas.

  * **Modo DBQL (Advanced):** Editor de texto contínuo que suporta operadores lógicos booleanos (`AND`, `OR`, `NOT`, `!`) e agrupamento por parênteses `( )`.

* **Deep Linking (Sincronização de URL):** Todo estado da busca é refletido nos parâmetros da URL (`?q={id}&m={modo}`). Consultas salvas carregam seu ID persistente na URL, enquanto buscas avulsas geram consultas temporárias e silenciosas no banco de dados para garantir que URLs copiadas funcionem exatamente igual para outros membros da equipe.

* **Auto-completar Sensível ao Contexto:** Conforme o usuário digita uma chave (ex: `category:`), o componente realiza um *debounce* em segundo plano e exibe sugestões de valores baseados no contexto da tela atual (ex: `issues`, `projects`).

* **Validação de Sintaxe e Linting em Tempo Real:**
  * O input detecta erros de sintaxe ao vivo (parênteses abertos, aspas soltas, literais mal formados).
  * Exibe feedbacks de erro sob a barra de pesquisa, impedindo a submissão de buscas quebradas.

* **Gerenciamento de Consultas Salvas:**
  * **Salvar:** Permite salvar a query atual com níveis de visibilidade (Privada, Compartilhada, Pública).

  * **Modificação (Dirty State):** Se uma consulta salva for carregada e posteriormente editada pelo usuário, a interface exibe um indicador de estado modificado (âmbar pulsante) e habilita a opção de re-salvar sobre a mesma entidade.

  * **Exclusão e Seleção rápida:** Dropdown integrado que permite alternar instantaneamente entre consultas e excluí-las com segurança.

* **Assistente Baseado em IA:** Modal integrado onde o usuário pode descrever em linguagem natural o que deseja buscar. O sistema gera um prompt perfeitamente formatado contendo o contexto atual da tabela e as regras oficiais da DBQL, pronto para ser colado em ferramentas de IA.
