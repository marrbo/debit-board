## 📝 Release Notes – v2026.8.5

### # Debit Board - Release Notes

**Versão:** v2026.8.5

**Tipo de Release:** Minor (melhorias e novos recursos)

---

### 🚀 Visão Geral

Esta versão foca em melhorias na **interface do painel de estatísticas (Stats)**, **paginação mais estável e intuitiva**, e **detalhamento de observações em um painel lateral**, além de correções no tratamento de datas e consolidação de dados.

---

### ✨ Novas Funcionalidades

1. **Painel Lateral (ObservationDrawer)**
   - Ao clicar em uma linha da tabela de observações, um painel lateral é aberto com informações detalhadas.
   - Agrupa dados em seções: Identificação, Detalhes do Problema, Descrição/Recomendação, Origem e Responsável.
   - Inclui link para busca no Azure DevOps (simulado) e campos adicionais como External ID.
   - Permite atribuir responsável diretamente pelo painel.

2. **Contador de Densidade de Severidade**
   - Adicionado filtros rápidos no cabeçalho da página Stats com contadores (🔴 Críticas, 🟠 Altas, etc.).
   - Um clique aplica o filtro correspondente na busca DBQL.

3. **Colunas Adicionais no Grid de Stats**
   - Adicionadas colunas de **Responsável** e **Ação** na tabela de observações.
   - Uso do componente `AssigneeSelect` para alterar o responsável inline.

4. **Paginação Aprimorada (Estilo Google)**
   - Botões de primeira/última página, navegação numérica estável (largura fixa).
   - Campo para digitar o número da página desejada.
   - Seletor de itens por página (10, 20, 50, 100).

5. **Conversão de Datas para o Tipo Correto**
   - Script para converter `firstSeen`, `lastSeen` e `slaDueAt` de string para `Date` no MongoDB.
   - Resolve o problema de filtros por data nas APIs.

---

### 🛠 Detalhes de Implementação

- **Frontend:**
  - Criação do componente `ObservationDrawer.tsx` para detalhamento.
  - Atualização do `StatsClient.tsx` para integrar o drawer, filtros de severidade e novas colunas.
  - Refatoração do `PaginationInfo.tsx` para layout estável e funcionalidades extras.
  - Adição do seletor de severidade no `PageHeader` via prop `filters`.

- **Backend:**
  - Ajustes na rota `/api/stats` para garantir filtragem segura com `$and`.
  - Correção no tratamento de `tenantId` para usar header/sessão.
