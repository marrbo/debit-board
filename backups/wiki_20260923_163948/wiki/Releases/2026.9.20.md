# 📝 Release Notes – v2026.9.20

**Versão:** v2026.9.20  
**Data de Lançamento:** 20 de setembro de 2026  
**Tipo de Release:** Minor (melhorias, correções e novos recursos)

---

## 🚀 Visão Geral

Esta versão consolida uma reestruturação profunda em **componentes de interface, segurança e visualização de dados**. Destacam-se a migração completa da biblioteca de gráficos para um padrão mais estável e visualmente refinado, o sistema de **impersonação de usuários** com isolamento por janela, o **controle de visibilidade e permissões em Consultas Salvas**, a **integração automática de detecção de HTTPS no NextAuth**, e uma **revisão geral da camada de DataTable** com suporte a modos de visualização, ações em lote contextuais e exportação vetorial em PDF.

---

## ✨ Novas Funcionalidades

### 🔀 Impersonação de Usuários (Admin)

- Admin pode se passar por qualquer usuário em uma **nova janela isolada**.
- Sessão do usuário alvo é refletida em toda a aplicação (nome, email, tenant, avatar, permissões).
- Banner visual de impersonação e ação "Stop Impersonating" disponíveis no menu de conta.
- Encerramento da impersonação fecha a janela e retorna o admin à sessão original automaticamente.
- Sessão de impersonação tem duração limitada (15 minutos).

### 🔐 Keycloak – Attribute Mapping de Tenant

- Suporte ao atributo customizado `tenantId` no User Profile do Keycloak.
- Mapeamento para claim no ID Token / Access Token / UserInfo configurável.
- Propagação automática do `tenantId` para a sessão NextAuth.
- Documentação de passos para criação de Protocol Mapper e validação via Evaluate.

### 🔒 Detecção Automática de Cookies Seguros (NextAuth)

- `useSecureCookies` agora é inferido automaticamente a partir da variável `NEXTAUTH_URL`.
- Compatível com ambientes HTTP (local) e HTTPS (produção) sem necessidade de alteração manual.
- Override explícito possível via variável `NEXTAUTH_USE_SECURE_COOKIES`.

### 💾 Consultas Salvas (Saved Queries)

- **Controle de visibilidade:** `private`, `shared`, `public` e `temporary`.
  - `public` — visível a qualquer tenant.
  - `shared` — visível a todo o tenant.
  - `private` / `temporary` — exclusivo do usuário criador.
- **Permissão de escrita por dono:** apenas o criador pode editar ou excluir a própria consulta. Admin edita apenas via impersonação.
- **Exclusão em lote** com confirmação contextual (nome único ou contagem).
- **Alteração de visibilidade em lote** via dialog dedicado.
- Reaproveitamento automático de consultas `temporary` ao salvar uma nova.

### 📊 Novo Componente de Gráficos (Nivo)

- Migração completa de MUI X Charts para **Nivo**, resolvendo definitivamente problemas de posicionamento de legendas.
- **Gráfico de linhas** com tooltip por fatia (slice) exibindo **todas as séries no mesmo X**, com cor, nome e valor.
- **Gráfico de pizza** com legenda à direita, símbolos coloridos por categoria e truncamento inteligente de rótulos longos.
- **Gráfico de barras empilhadas** com legenda no topo e maior área útil para o plot.
- Tema claro/escuro unificado e aplicável a todos os gráficos.

### 🎛️ Componente SlideToggle Padronizado

- Componente reutilizável para alternância entre modos em uma única linha.
- Suporte a ícones, rótulos customizados e cores contextuais.
- Cálculo preciso de knob deslizante com alinhamento de texto centralizado.
- Integração com hooks de persistência de preferência por página.

### 📋 DataTable – Ações em Lote, Modo Cards e Exportação Vetorial

- **Modo de visualização alternável** (tabela ↔ cards) com persistência por endpoint.
- **Toolbar superior fixa** com contagem de registros, seletor de itens por página, alternância de modo e exportações.
- **Paginação na base** com seleção contextual e ações em lote (Excluir, Mudar visibilidade, etc.).
- Suporte a **`rowSelectable`** — apenas linhas permitidas podem ser selecionadas.
- **Legenda de seleção compacta** (apenas ícone "X" para limpar).
- **Exportação PDF vetorial** por coluna via `pdfCellRenderer`, permitindo desenhar elementos gráficos (shields de severidade) diretamente no relatório.

### 📄 Exportação PDF com Shields de Severidade

- Coluna de severidade do Dashboard renderizada como **ícones vetoriais coloridos** (C/H/M/L) no PDF.
- Contagem exibida abaixo de cada shield.
- Altura mínima de célula ajustada automaticamente para acomodar os elementos.
- Utilização de `didDrawCell` para integração ao `jspdf-autotable`.

### 🗑️ Exclusão de Times com Validação

- Botão **Excluir** adicionado ao rodapé do `TeamDrawer` com dialog de confirmação.
- Exclusão em lote via DataTable.
- **Bloqueio de exclusão** quando há projetos vinculados ao time (`409 Conflict` com lista de IDs bloqueados).

### 🎨 Background Animado da Página de Login

- Ícones de segurança flutuantes (escudo, cadeado, chave, biometria, etc.).
- **Animação paralela de float + glow pulse** com composição em GPU.
- **Parallax responsivo ao mouse** com deslocamento suave e desativado em touch / `prefers-reduced-motion`.
- Paleta sutil com três variações cromáticas e vinhetas que guiam o olhar ao card.

## 🛠 Melhorias e Correções

### 🔧 Rota de Estatísticas (`/api/stats`)

- Padronização para aceitar `q` (ID de SavedQuery ou DBQL cru) em vez de `search`.
- Resolução server-side de IDs de consultas salvas respeitando visibilidade.
- Filtro por `teamId` inline, alinhado ao padrão do `/api/dashboard/stats`.
- Tratamento de erros com `Sentry` e respostas padronizadas.
- Documentação JSDoc compatível com o gerador OpenAPI.

### 🔧 Rota de Estatísticas do Dashboard

- Correção no cálculo de grupos por categoria (ignora `patternId` nulo/vazio).
- Compatibilidade com `patternId` armazenado como `ObjectId` ou `string`.

### 🔧 Sessão NextAuth

- Propagação completa de `isAdmin`, `isActive`, `tenantId`, `organization`, `onboardingCompleted` e `azureSettings` do token para a sessão.
- Adição de `jti` (JWT ID) ao token.
- Impersonação força `isAdmin: false` na sessão do usuário alvo.
- `requireSession` e `requireAdmin` corrigidos para refletir os dados reais da sessão.

### 🔧 Build e Compatibilidade

- Correção de erros de importação de Mongoose em Client Components via `server-only` + separação entre `lib/db.ts` e `lib/utils.ts`.
- Configuração `turbopack.resolveAlias` para blindar contra regressões futuras.
- Atualização de `package.json`: semver válido, remoção de pacotes deprecados, `overrides` para dependências transitivas.

### 🔧 Filtros e Paginação

- Ordenação de colunas com `lookup` (nome do projeto) corrigida via `$addFields`.
- Rota de times com ordenação dinâmica e paginação correta.
- Montagem de URLs de requisição resiliente a query strings pré-existentes.

### 🔧 SlideToggle

- Correção do alinhamento interno entre knob deslizante e texto.
- Substituição de truque de truncamento por ajuste de tipografia e largura.
- Uso consistente em todos os cards do Dashboard e Stats.

### 🔧 Exportação PDF

- Filtro automático de colunas de ação (não exportáveis).
- Busca de todos os dados via `all=true` antes da geração.
- Títulos e nomes de arquivos seguros (fallback para valores padrão).
- Compartilhamento de cabeçalho e rodapé via `pdfShared`.

### 🔧 Hooks de Confirmação

- `useConfirm` corrigido para ser sempre chamado no topo do componente (Rules of Hooks).
- Todos os `confirm()` nativos substituídos pelo dialog MUI.
- Botão "Cancelar" do dialog com hover vermelho para ações destrutivas.
- Ações assíncronas executadas dentro do próprio dialog com estado de loading.

### 🔧 Checkbox em Tabelas

- Clique no checkbox não dispara mais o `onRowClick` da linha.
- `selectAll` respeita apenas as linhas selecionáveis (via `rowSelectable`).

### 🔧 AdminTabs e Sidebar

- `useConfirm` migrado para o topo dos componentes.
- Impersonação abre em nova janela e reflete dados atualizados.
- Popover de conta com estado de impersonação e ação contextual.

### 🔧 Teams / TeamDrawer

- Contagem de projetos (`projectCount`) agora calculada via `$lookup` em `Projects` — consistente com a regra de negócio de bloqueio de exclusão.
- Índice recomendado em `{ tenantId, teamId }` para acelerar as agregações.

### 🎨 Ajustes Visuais e de UX

- Uniformização de cards de gráfico com título e controles na mesma linha.
- Barras com rótulos brancos sobre fundo colorido para legibilidade.
- Legenda do gráfico de barras movida para o topo.
- Truncamento controlado de rótulos longos no eixo X e nas legendas.
- Paleta compartilhada entre pizza e legenda, evitando símbolos sem cor.
- Tema claro/escuro unificado para todos os gráficos Nivo.

## ⚠️ Considerações

- A migração para Nivo substitui completamente o uso do MUI X Charts nos gráficos principais; componentes legados do MUI X Charts podem ser removidos em versões futuras.
- A impersonação depende de JWT assinado com `NEXTAUTH_SECRET` e cookies de curta duração; qualquer alteração nesse segredo invalida sessões ativas.
- Consultas Salvas criadas antes desta versão podem não ter `userId` preenchido; o fluxo de atualização trata o backfill automaticamente.
- A detecção automática de `useSecureCookies` depende de `NEXTAUTH_URL` estar configurada corretamente no ambiente.
- O script de migração de IDs permanece recomendado para ambientes com dados históricos.
- Índice `{ tenantId: 1, teamId: 1 }` em `Project` é recomendado para performance das agregações de contagem de projetos por time.

## 🔄 Como Atualizar

```bash
git pull
npm install
npm run build
npm run start
```

**Migração necessária:** Execute os scripts de migração de dados para garantir consistência nos IDs e na estrutura de scans:

```bash
npm run fix:ids
npm run rebuild:scans
```

**Variáveis de ambiente recomendadas:**

```env
NEXTAUTH_URL=https://seu-dominio.com
NEXTAUTH_SECRET=<secret-forte>
```
