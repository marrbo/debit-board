## 🎯 Ordem recomendada para fechar as sprints

Se for priorizar por **impacto no workflow de triagem do analista**:

1. **Prompt 3.2** (persistência) — é o que mais dói no dia a dia: perder filtros ao abrir uma observação é frustrante
2. **Prompt 2.2** (hover actions) — permite resolver triagem sem abrir painel, ganho enorme de produtividade
3. **Prompt 2.1** (origem) — contexto que hoje exige abrir cada card
4. **Prompt 1.1** (badges) — consistência visual, mas o usuário já lê severidade hoje
5. **Prompt 1.2** (accent lateral) — refinamento visual
6. **Prompt 3.1** (paginação) — mexe em layout consolidado; maior risco de regressão

Se quiser, ataco uma por uma em ordem e fecho esta sprint de verdade — cada prompt dá uma resposta isolada com arquivo completo, sem novelas. Só me diga por qual começar.
